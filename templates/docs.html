REST API v1.0.0 Public & Open

Dokumentasi REST API Lokeriva.vercel.app

Lokeriva.vercel.app API menyediakan akses langsung dan terbuka ke ribuan lowongan kerja teragregasi dari berbagai portal karir di Indonesia serta lowongan kerja remote WFH global. Bebas digunakan untuk aplikasi mobile, bot Telegram/Discord, skrip automasi, atau dashboard karir.

Kebijakan Akses & Rate Limiting

API menggunakan rate limiting yang ramah dan bersahabat: 120 permintaan / menit untuk penelusuran JSON, dan 30 permintaan / menit untuk ekspor PDF. Jika limit terlampaui, server akan mengembalikan status HTTP 429 Too Many Requests dengan header Retry-After.

Pencarian, Filter Lokasi & Loker

Mengambil daftar lowongan kerja dengan dukungan kata kunci pencarian, filter sumber, kategori, lokasi spesifik, tipe lokasi (Remote vs On-site), serta pagination.

Parameter Query (Opsional):

Parameter Tipe Default Keterangan
q string kosong Kata kunci pencarian (misal: Admin, Makassar, Bidan, Python)
location_type string all Tipe lokasi: all (semua), remote (khusus WFH), atau onsite (khusus kantor/di tempat)
location string kosong Filter wilayah / kota (misal: Makassar, Jakarta, Surabaya, Bandung)
source string kosong Filter sumber tertentu (misal: Kalibrr Indonesia, Disnakerja (WP))
category string kosong Filter kategori (misal: Remote, Admin, Medis)
sort string newest Urutan hasil: newest, title, atau company
page integer 1 Nomor halaman yang ingin ditampilkan
limit integer 20 Jumlah item per halaman (maksimal 100)

Contoh Permintaan (cURL):

# Metode GET (Query String) curl -X GET "https://lokeriva.vercel.app/api/jobs?q=Admin&location=Makassar&limit=5" # Metode POST (JSON Body Payload) curl -X POST "https://lokeriva.vercel.app/api/jobs" \ -H "Content-Type: application/json" \ -d '{"q": "Admin", "location": "Makassar", "limit": 5}'

                Statistik Agregasi
            

            

                

                    Mendapatkan ringkasan jumlah lowongan kerja, sumber aktif, rasio loker remote vs lokal, dan waktu pembaruan terakhir.
                

                

                    
                    
curl -X GET "https://lokeriva.vercel.app/api/stats"

                

                

                    
                    

                        
                        

                    

                

            

        


        
        

            

                

                    GET
                    /api/sources
                

                Daftar Sumber Aktif
            

            

                

                    Mendapatkan daftar semua portal loker, API, dan ATS yang saat ini aktif menyumbang data beserta jumlah itemnya.
                

                

                    
                    
curl -X GET "https://lokeriva.vercel.app/api/sources"

                

                

                    
                    

                        
                        

                    

                

            

        


        
        

            

                

                    GET
                    /export/pdf
                

                Ekspor PDF dengan Link Aktif
            

            

                

                    Menghasilkan file PDF terstruktur berformat A4 dengan hyperlink aktif yang dapat diklik langsung di viewer PDF manapun untuk melamar pekerjaan.
                

                

                    Parameter opsional: q (kata kunci), location (wilayah), location_type (remote/onsite), dan source.
                

                

                    
                    
curl -O -J "https://lokeriva.vercel.app/export/pdf?q=Admin&location=Makassar"

                

                

                    
                         Unduh Contoh PDF
                    
                

            

        


        
        

            

                

                    GET
                    /export/csv
                

                Ekspor CSV untuk Excel
            

            

                

                    Mengunduh data lowongan dalam format CSV dengan encoding UTF-8 BOM dan delimiter semicolon (;) sehingga rapi saat dibuka langsung di Microsoft Excel PC atau Android.
                

                

                    
                    
curl -O -J "https://lokeriva.vercel.app/export/csv"
